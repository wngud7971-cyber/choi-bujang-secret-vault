# 케셰브_배주형 · 21단계 로컬 앱 검토본

이 브랜치는 `codex/step21-review`이며, 13~20단계에서 작성한 보안 Agent 화면과 21단계 학생 문서를 검토하는 범위입니다. 전체 프로젝트 보존본은 같은 저장소의 main 커밋 `bf267891709fe562d3a10cb6d9bd85706b4482ee`입니다. main의 기존 1~12단계·XDR 코드·테스트·Git 기록은 변경하지 않습니다. 검토본에는 `on-client/` 전체와 이 앱에 맞춘 학생 문서를 포함합니다.

목적은 본인 계정·기기·세션, 선택한 업무 앱의 접근 판정, 본인 보안 기록과 근거·규칙, 상태·알림, AI 연결·사건 설명·조치 결과, 승인된 공개 패키지의 정확한 설치 버전별 OSV 결과를 표시하는 것입니다. 학생 표시 함수는 `on-client/student/extension.mjs`이며 제공된 서버·인증·요청·취소·집행 코드는 그대로입니다.

구성은 **브라우저 → 로컬 앱 서버 → 명시적으로 연결된 접근 제어·XDR 시스템 / AI 게이트웨이**입니다. 기본 실행은 연결 없음, `--demo`는 예제 자료입니다. 실제 연결 성공·AI 사건 설명·조치 효과는 각각 별도로 확인해야 합니다.

실행 조건은 `on-client/package.json`의 Node.js **24.19.0**이며 제공 실행 도구는 Node.js 22~24를 허용합니다. 확인한 환경은 Windows win32/x64, Node v24.19.0, PowerShell 7.6.5, Windows PowerShell 버전 조회 5.1.26100.9711, Git 2.53.0.windows.3입니다. 다른 OS·브라우저 버전·운영 native 호스트 연결은 미확인입니다. 앱 버전은 0.2.11입니다.

Git 최상위의 `on-client`에서 실행합니다. 이 앱은 외부 npm 의존성이 없어 별도 패키지 설치 단계가 없습니다.

```powershell
Set-Location -LiteralPath 'C:\Users\82109\Documents\ChatGPT\hackert0n\step21-review\on-client'
node .\src\server.mjs
```

다른 PC에서는 자신의 검토 브랜치 폴더로 경로를 바꿉니다. `ON_PORT` 미설정 시 **http://127.0.0.1:5189/** 를 엽니다. 종료는 실행 창에서 Ctrl+C, 재실행은 같은 폴더에서 같은 명령입니다. 기본 모드에서 `ENGINE_NOT_CONNECTED`가 나오는 것은 엔진 연결이 준비되지 않았다는 뜻이며 서버 시작 실패와 구분합니다.

실행 위치·종료·재실행·글 구성도·학생 함수와 제공 코드의 경계·장애 대응·재현 기록은 [학생 실행 설명서](docs/STUDENT_RUNBOOK.md)에 있습니다. 비밀값 없는 [설정 견본](on-client/.env.example)은 자동으로 읽히지 않습니다. 실제 `.env`와 개인 자격 파일은 제출에서 제외합니다.

이 브랜치의 공식 통과와 서버 비밀정보 검사 해제 여부는 아직 확인하지 않았습니다. 21단계에는 **이 검토 브랜치의 실제 40자리 커밋**을 과제 화면에 직접 제출합니다. main에 병합하거나 main의 파일을 삭제할 필요는 없습니다.
