- 원본 전체 프로젝트의 기준 커밋: ea323be66ee3f18fd260c8ca89da6ec2de5f6eb1
- 포함: on-client/student 전체, on-client/public 전체(화면의 모듈과 이미지 포함)
- 위 두 폴더는 기준 커밋과 Git 객체가 동일하며 학생 구현과 제공 UI를 수정하거나 압축하지 않았습니다.
- 포함된 JavaScript/HTML/CSS 원문: 189,631바이트. 문서와 이미지는 별도입니다.
- 제외: 이전 단계 프로젝트, 테스트, 서버, 연결/AI/조치의 서버 모듈, 실행 도구. 원본 전체 프로젝트와 Git 기록은 보존합니다.
