### 2.2 현재 실행과 기존 방어 코드 사이의 경계

3. ‘보호 현황’에서 ‘연결 없음’과 계정·기기·세션의 조회 실패 안내를 확인한다. 이번 기본 실행 조건에서 관측한 상태이며 실제 연결 성공으로 해석하지 않는다.
4. ‘도움정보’의 ‘도움정보 불러오기’를 누른다. engine의 `disconnected / ENGINE_NOT_CONNECTED`, AI의 `configured: false / authorized: false`를 확인한다. 시각과 요청 식별자는 매 실행마다 달라질 수 있다.
5. ‘업무 앱’·‘보안 기록’ 메뉴와 ‘다시 불러오기’는 추가 화면 확인에 사용할 수 있다. 이 버튼들을 사용자가 모두 조작했다고 기록하지 않으며, 기본 미연결 상태에서는 실제 목록·판정을 기대하지 않는다.
6. 종료는 서버를 실행한 PowerShell 창에서 Ctrl+C다. 다시 실행할 때는 위와 같은 명령을 사용한다.

예제 판정을 다시 확인하려면 실행 창에서 Ctrl+C로 기본 서버를 종료한 뒤 위 명령 끝에 `--demo`를 붙여 실행한다. 이 절차는 기본·예제 서버가 같은 포트를 동시에 사용하지 않게 한다. 예제 모드의 자료실 allow·저장소 deny는 앞선 HTTP 점검 결과이며, 사용자가 예제 화면의 버튼을 누른 것으로 기록하지 않는다. 기본 모드로 돌아오려면 예제 서버를 종료하고 위 원래 명령으로 다시 실행한다.
