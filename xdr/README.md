# XDR 보너스 경보

## 보너스 xdr-06 · exfiltration

`npm run xdr:run -- exfiltration`으로 「자료 빼돌리기를 잡아 냅니다」를 실행합니다. 원본 경보 30건은 차단 10·알림 10·기록 10이며 정상 차단은 0건입니다. `read-alerts.mjs`는 비밀값을 가린 다섯 항목 30줄을 읽고 `decide.mjs`는 상단 패턴과 `decide(alert)`만 가진 독립 파일입니다. 근거는 MITRE T1041·T1048이며 실제 프로토콜·목적지 승인 목록의 수집 결과는 없습니다.

호스트 실행기만 `respond.mjs`를 호출해 근거·15분 만료가 있는 목적지 IP 거부 규칙을 저장하고 기존 로그 뒤에 가린 알림을 쌓습니다. 같은 목적지의 정상/애매한 활동은 보호합니다. `src/ztna.mjs`의 서버 설정 `resolveDestination`을 통해서만 목적지를 공급하며 기존 요청 계약·인바운드 출발 주소 규칙은 보존합니다. 로컬 경보 재현은 공격 목적지 10거부·정상 10허용·애매한 거부 0건입니다. 운영 목적지 연결·실제 PC 송신 차단·재배포·심판 판정은 미실행입니다. 자세한 연결 계약과 한계는 루트 README xdr-06 기록을 참고합니다.

이 폴더는 보너스 여섯 개의 연습 경보입니다. 경보는 수업용으로 만든 Wazuh 모양이며, 실제 로그가 아닙니다. 정답은 이 저장소에 없습니다.

## 경보 묶음

`xdr/fixtures/<moduleKey>.json` 을 읽습니다. `moduleKey` 는 아래 여섯 개입니다.

| moduleKey | 보는 것 |
|---|---|
| `brute-force` | 짧은 시간에 몰린 로그인 실패 |
| `web-injection` | 웹 요청에 섞인 주입 형태 |
| `known-cve` | 이미 공개된 취약점을 노린 요청 형태 |
| `persistence` | 다시 켜도 남도록 심긴 서비스·예약 작업 |
| `privilege` | 평범한 계정의 갑작스러운 권한 상승 |
| `exfiltration` | 처음 보는 곳으로 빠지는 큰 전송 |

한 파일에는 명확한 공격, 애매한 시도, 정상 이벤트가 함께 들어 있습니다. 주소는 문서용 대역만 쓰고, 계정은 `user01` 같은 가상 이름입니다. `known-cve` 의 원격 조회 구문은 문서용 표기입니다. 그 문자열을 다른 시스템에 넣거나 변형하지 않습니다.

## 학생이 만드는 파일

항목마다 `xdr/<moduleKey>/decide.mjs` 를 만듭니다. `decide(alert)` 를 내보냅니다. 비동기 함수여도 됩니다. 반환은 아래 세 값입니다.

- `action`: `block`, `alert`, `record` 중 하나
- `confidence`: 0 이상 1 이하 숫자
- `reason`: 짧은 이유

명확한 공격은 `block`, 애매한 시도는 `alert`, 정상 이벤트는 `record` 입니다. 경보 원본은 고치지 않습니다.

## 실행

저장소 루트에서 항목 키 하나를 넣습니다.

```
node scripts/xdr-run.mjs brute-force
```

`npm run xdr:run -- brute-force` 도 같은 명령입니다. 실행기는 해당 경보마다 `decide` 를 부르고, 결과를 `xdr/<moduleKey>/result.json` 에 씁니다. 형식은 `aleph.xdr.result.v1` 이고, `decisions` 에는 경보 id·행동·확신도·이유가, `counts` 에는 `block`·`alert`·`record` 건수가 있습니다.

## 보너스 xdr-04 · persistence

`npm run xdr:run -- persistence`로 「몰래 심어진 프로그램을 찾아냅니다」를 실행합니다. `persistence/decide.mjs`는 패턴 상수를 포함하고 다른 파일·패키지·파일 접근·네트워크 없이 `decide(alert)`만 내보냅니다. 확인용 `read-alerts.mjs`는 별도이며 원본 경보 24건을 가린 다섯 항목 24줄로 읽습니다. `patterns.json`에 서비스(T1543)·예약 작업(T1053)·시작 폴더(T1547.001)의 조건과 한 줄 근거가 있습니다.

호스트 실행기만 `respond.mjs`를 불러 별도 거부 문서와 15분 만료·근거 경보 번호를 저장하고 가린 알림을 공통 로그 뒤에 쌓습니다. 앞선 세 모듈과 기본 정책은 보존합니다. 동일 출발 주소의 정상/애매한 경보는 차단을 보류합니다. 결과는 8차단·8알림·8기록, 실제 연결부 재현은 공격 8거부·정상 8허용·정상/애매한 거부 0건입니다. 격리는 확인된 소켓 출발 주소 기준이며 검증된 기기 ID 연결·운영 PC 격리·열린 연결 회수·심판 판정은 미실행입니다. 과거 경보의 만료 규칙은 현재 되살리지 않습니다.

## 보너스 xdr-03 · known-cve

`npm run xdr:run -- known-cve`로 알려진 취약점 과제를 실행합니다. `known-cve/decide.mjs`는 다른 파일·패키지 없이 `decide(alert)`만 내보내는 단독 판정 파일입니다. `read-alerts.mjs`는 확인용으로만 사용하며 원본 경보·요청 원문·비밀값을 출력하지 않습니다. `patterns.json`의 조건·이름·한 줄 근거는 판정 파일 상단 상수와 같습니다.

호스트 실행기만 `known-cve/respond.mjs` 후처리를 호출합니다. 별도 `deny-rules.json`을 만들고 기존 `alerts.log`에 가린 경보를 추가합니다. 기존 두 보너스 규칙은 수정하지 않습니다. `src/xdr-policy.mjs`의 기존 연결이 새 문서를 추가로 읽으며 정상·애매한 접속 보호와 15분 만료를 적용합니다. `result.json`은 8차단·8알림·8기록, `verification.json`은 명확 8건 거부·정상 8건 허용·정상/애매한 거부 0건을 기록합니다. 과거 경보 시각의 로컬 재현이며 운영 연결과 심판 판정은 미실행입니다. 자세한 상태·검증·배포 제한은 루트 README의 xdr-03 기록에 있습니다.

반환 형식이 틀린 경보는 `record` 로 남고, 오류 한 줄이 출력됩니다. 실행기 자체는 네트워크를 쓰지 않습니다. 판정자는 격리된 환경에서 같은 명령을 다시 실행해 결과를 봅니다. 이미 커밋된 `result.json` 만으로 판정이 끝나지 않습니다.
